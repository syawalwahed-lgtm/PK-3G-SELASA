# Aplikasi Pendidikan Kesihatan Tahun 3 — Misi Bebas Nyamuk

## Kandungan pakej
- `index.html` — aplikasi interaktif kendiri, HTML/CSS/JavaScript.
- `bank-soalan.md` — tepat 25 soalan objektif berserta empat pilihan, skema dan penerangan.
- `pemetaan-kurikulum.md` — pemetaan SK/SP dan batasan pengesahan.
- `laporan-pengujian.md` — senarai pemeriksaan kod dan ujian manual yang masih perlu dijalankan.

## Cara menggunakan
1. Muat turun dan ekstrak fail ZIP.
2. Buka `index.html` dengan Chrome, Edge, Firefox atau Safari versi terkini.
3. Masukkan nama murid dan tekan **Mula Pembelajaran**.
4. Teroka nota, buka video jika internet tersedia, lengkapkan permainan dan jawab kuiz.
5. Pada laporan, tekan **Cetak / Simpan PDF**. Dalam dialog cetak, pilih pencetak atau **Save as PDF** jika disokong.
6. Audio boleh dihidupkan/matikan menggunakan butang di bahagian atas. Suara menggunakan ciri pertuturan pelayar jika tersedia.

## Keperluan
- Tiada pelayan atau akaun diperlukan.
- Nota, permainan dan kuiz berfungsi secara setempat.
- Video YouTube memerlukan internet dan mungkin tertakluk pada sekatan rangkaian/peranti.
- Kemajuan disimpan menggunakan `localStorage` dalam pelayar pada peranti itu. Ia bukan sistem akaun dan tidak disegerakkan ke peranti lain.

## Terbitkan melalui GitHub Pages
1. Log masuk ke GitHub dan cipta repositori baharu, contohnya `pk-tahun3-misi-bebas-nyamuk`.
2. Muat naik `index.html` ke akar repositori (root), bersama fail Markdown jika mahu.
3. Buka **Settings → Pages**.
4. Di bahagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, kemudian **Save**.
6. Tunggu sehingga GitHub Pages memaparkan pautan laman. Buka pautan tersebut dan uji semua ciri dari telefon dan komputer.
7. Jangan anggap laman sudah diterbitkan sehingga pautan sebenar muncul dalam Settings → Pages dan berjaya dibuka. Pakej ini belum diterbitkan secara automatik oleh pembangun.

## Kurikulum dan keselamatan
Rujuk `pemetaan-kurikulum.md`. Label “Misi Bebas Nyamuk” ialah tajuk pedagogi. Guru perlu mengesahkan RPT semasa sekolah. Murid tidak boleh mengendalikan racun serangga, memanjat tempat tinggi atau membersihkan kawasan berbahaya tanpa orang dewasa.
